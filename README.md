# 📌 Web Öğrenci Sistemi

**Web Öğrenci Sistemi**, ASP.NET  kullanılarak geliştirilmiş bir öğrenci not kayıt sistemidir. Bu proje, öğrencilerin notlarını ekleyebildiği, güncelleyebildiği ve görüntüleyebildiği dinamik bir web uygulamasıdır.

## 🚀 Proje Özellikleri

  🔹 **ASP.NET ile web tabanlı öğrenci yönetim sistemi**
  🔹 **Entity Framework  ile veritabanı yönetimi**
  🔹 **Öğrenci bilgilerini CRUD (Create, Read, Update, Delete) işlemleriyle yönetme**
  🔹 **Bootstrap & CSS ile responsive arayüz**
  🔹 **SQL Server ile veri saklama**
  🔹 **DataSet Kullanımı**

## 🛠️ Kullanılan Teknolojiler

- **ASP.NET**
- **Entity Framework**
- **SQL Server**
- **LINQ**
- **Data Set**
- **Bootstrap & CSS**
- **JavaScript & jQuery**

## 🔧 Kurulum

1. **Projeyi klonlayın:**
   ```sh
   git clone https://github.com/bhmberkan/web_Ogrenci_sistemi1.git
   ```
2. **Bağımlılıkları yükleyin:**
   - Gerekli NuGet paketlerini yükleyin.
3. **Veritabanını yapılandırın:**
   - `appsettings.json` dosyasında bağlantı stringini güncelleyin.
   - Migration işlemlerini gerçekleştirin:
     ```sh
     dotnet ef migrations add InitialCreate
     dotnet ef database update
     ```
4. **Projeyi çalıştırın:**
   - Visual Studio veya uygun bir IDE kullanarak projeyi başlatın.
